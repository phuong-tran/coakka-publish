# Consuming CoAkka Runtime npm packages

Install the package that matches your application host.

| Host | Package guide |
| --- | --- |
| Node.js | [Node.js connector on npm](https://www.npmjs.com/package/coakka-v2-connector-node) |
| Bun | [Bun connector on npm](https://www.npmjs.com/package/coakka-v2-connector-bun) |
| Electron | [Electron connector on npm](https://www.npmjs.com/package/coakka-v2-connector-electron) |

Each package includes a `CONSUMING.md` file with guidance for its exact version.
The [current package ledger](docs/common/current-packages.md) and
[compatibility matrix](docs/coakka-runtime/reference/compatibility-matrix.md)
list supported versions and native targets.
