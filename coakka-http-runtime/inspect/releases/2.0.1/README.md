# CoAkka HTTP Runtime Inspect 2.0.1

Standalone Inspect embeds HTTP Runtime Core generation 2.0. Use the archive
for your OS and architecture. Compare its SHA-256 with [SHA256SUMS](SHA256SUMS)
before extracting it.

| Target | Archive |
| --- | --- |
| macOS ARM64 | [Download](coakka-http-runtime-inspect-2.0.1-macos-aarch64.tar.gz) |
| Linux ARM64 | [Download](coakka-http-runtime-inspect-2.0.1-linux-aarch64.tar.gz) |

The installed application passed startup, connect and refusal, OpenAPI,
route requests, disconnect and shutdown on macOS ARM64, Rocky Linux 8.10
ARM64 and Raspberry Pi 5. Follow the [installation guide](../../README.md)
and [walkthrough](../../walkthrough.md).
