# CoAkka HTTP Runtime for JavaScript

Current repository release:
[`1.0.0+d8deb6b821cdd90b69fa7d8e1c85629aac164315-26a28a1`](releases/1.0.0+d8deb6b821cdd90b69fa7d8e1c85629aac164315-26a28a1/README.md).

One private npm-format tarball carries documented JavaScript/TypeScript APIs
and Node-API/Core prebuilds for all five targets. It supports Node 22+ and Bun
1.3+. It can be installed from the local/downloaded tarball; npm registry
publication remains closed.
