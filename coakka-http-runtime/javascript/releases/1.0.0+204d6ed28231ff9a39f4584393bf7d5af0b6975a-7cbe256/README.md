# CoAkka HTTP For JavaScript And TypeScript 1.0.0

This private npm tarball contains exact runtime and JavaScript addon pairs for all five release
targets. The loader verifies target, runtime digest, addon digest and runtime-owned
release metadata before loading.

Node 22 is the execution baseline. Bun 1.3 is qualified on macOS and Linux
ARM64. The package exposes the host-inline `Builder`/`Service` API and the
complete low-level ABI 8 projection.
