# CoAkka HTTP for Node And Bun 1.0.0

`coakka-http-1.0.0.tgz` is an npm-format package with TypeScript declarations,
documented JavaScript and exact Node-API/Core prebuilds for all five targets.
Its SHA-256 is
`650c26c3cb49ce1de626032e58dd8e308c956921e43c7b7f5d139de915329fd0`.

The package is deliberately marked private because npm publication is a
separate gate. Local tarball installation is supported for Node 22+ and Bun
1.3+.
