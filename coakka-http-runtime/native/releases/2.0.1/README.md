# CoAkka HTTP Runtime native SDK 2.0.1

SDK 2.0.1 packages Core generation 2.0 with public C ABI 10. It includes
`coakka/http/host.h` and the `CoAkkaHttpHost` CMake package.

| Target | Download |
| --- | --- |
| Linux ARM64 | [Archive](coakka-http-runtime-native-2.0.1-linux-aarch64.tar.gz) |
| Linux x86-64 | [Archive](coakka-http-runtime-native-2.0.1-linux-x86_64.tar.gz) |
| macOS ARM64 | [Archive](coakka-http-runtime-native-2.0.1-macos-aarch64.tar.gz) |
| Windows ARM64 | [Archive](coakka-http-runtime-native-2.0.1-windows-aarch64.tar.gz) |
| Windows x64 | [Archive](coakka-http-runtime-native-2.0.1-windows-x86_64.tar.gz) |

Compare the archive SHA-256 with [SHA256SUMS](SHA256SUMS) before extracting
it. On WSL2, use the Linux SDK for the architecture of the WSL process.

Use [the native SDK guide](../../README.md) to build against the installed
headers and library. The versioned archives match the SDK downloads on the
[Go v2.0.1 release](https://github.com/phuong-tran/coakka-http-runtime-go/releases/tag/v2.0.1).
