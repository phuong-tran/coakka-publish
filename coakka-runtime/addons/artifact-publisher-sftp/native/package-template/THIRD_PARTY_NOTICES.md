# Third-Party Notices Template

This package template is not a release notice. Before promotion, replace this
text with the complete notices and license texts for exact target contents:
libssh2 on every target, OpenSSL on macOS/Linux, Windows WinCNG system use, and
any compression library linked by a target module.

The release manifest and this notice must agree on dependency names and
versions. A target-specific crypto provider must be identified explicitly; it
must not remain `target-package-defined` in a promoted artifact.
