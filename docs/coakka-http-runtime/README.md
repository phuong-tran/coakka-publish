# CoAkka HTTP Runtime Documentation

CoAkka HTTP Runtime is the independent HTTP server/client product. Start with
the [introduction](introduction.md), then choose a host in the
[product catalog](../../coakka-http-runtime/README.md) or run a
[language sample](https://github.com/phuong-tran/coakka-samples/blob/main/coakka-http-runtime/README.md#languages).
Its packages, configuration and version are separate from CoAkka Runtime.
