This compatibility-only patch lowers the module `go` directive from `1.22`
to `1.18`. The package has no external Go module dependencies; the module's
consumer smoke uses the Go 1.18 `any` alias and defines the current complete
source-tree floor. Go 1.18 is a compatibility floor, not a production
toolchain recommendation; production builds should use a currently supported
Go release.

Public Go CI run `32040392495` passes module tidiness, source tests, public-doc
language checks, and all five native-payload shape checks on Linux x86-64 with
Go `1.18.10` and stable Go `1.26.6`. Sample run `32040555570` passes both the
Go `1.18.10` and stable logger basic/pressure jobs. Clean remote-tag consumers
complete logger info, emit, drain, and counter checks on macOS ARM64 with
stable Go and on Ubuntu 22.04 ARM64 with Go `1.18.10`. Stable Go additionally
passes `go vet` and the race detector; `govulncheck` reports no reachable
vulnerability.

The public Go API and production Go implementation are unchanged except for
the exported package version constant. Every bundled native tree object is
byte-identical to `v1.2.5`; the patch retains logger connector/native version
`1.2.1` and generation `1.2.1+f50756ebff0d`.
