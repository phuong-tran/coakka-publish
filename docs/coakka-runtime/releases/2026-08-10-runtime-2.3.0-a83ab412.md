# CoAkka Runtime 2.3.0

Runtime `2.3.0` promotes the Stream Lane alongside the existing File Lane.
The release keeps application policy in the app-host: CoAkka transports ordered
frames and reports bounded pressure and wait signals, while the application
decides how to adapt its source, encoding, quality, rate, or destination.

## File And Stream Lanes

File Lane remains the bounded path for transferring a complete immutable file
with progress, integrity, cancellation, retained terminal state, and explicit
cleanup.

Stream Lane is the bounded path for current ordered frames such as camera,
media, sensor, audio, inference, or relay traffic. It reports neutral transport
pressure to both app-hosts without interpreting codecs, resolution, bitrate, or
business policy.

Use normal runtime messages for commands, grants, metadata, and coordination.
Keep file and stream bytes on their dedicated lanes.
