This refresh brings the logger family onto the same `1.2.1` product line as
the current runtime train while widening the published logger package surface
to `macos-aarch64`, `linux-aarch64`, `linux-x86_64`, `windows-aarch64`, and
`windows-x86_64`.

User-facing changes:

- logger native C/C++ now publishes a Windows-aware CMake package config and a
  five-platform native archive
- logger JVM now publishes current Maven artifacts over the same five-platform
  embedded native set
- Python, Node.js, Go, C#, and Rust now publish `1.2.1` packages over the same
  logger native package generation
- Mojo and Zig source packages now refresh over the same logger native package
  and the same five-platform bundled native set

Validation covered:

- logger core C tests on macOS plus real Linux `aarch64` and `x86_64` rebuilds
- Windows `aarch64` and `x86_64` cross-builds for the public logger core
- packaged smokes for JVM, Python, Node.js, Go, C#, and Rust
- source/package smokes for Mojo and Zig
- Maven local consumer smoke for the logger JVM lane
- publish-side `scripts/verify-public-surface.sh`
