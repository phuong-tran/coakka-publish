# Runtime 1.3.3 Public Artifact Train

Date: 2026-07-31

This release refreshes the public runtime artifact train over native generation
`1.3.3+282f3ad`.

## Native Boundary

The native package is published at:

```text
runtime/native/releases/1.3.3+282f3ad/
```

The package keeps the host-facing runtime contract on the public C ABI. Public
native libraries expose the reviewed 88-symbol surface and pass platform
dependency and export gates. Generated protobuf, Abseil, C++ runtime internals,
and private transport schema are not part of the public dynamic-library
surface.

## Runtime Tools

The native CLI is published as:

```text

```

Runtime Inspect is published as:

```text
coakka-tools/coakka-runtime-inspect/releases/1.3.3+ae4be45/
```

Both tools consume the public C ABI. They do not link a second generated
runtime schema into the process.

## Package-Manager Status

Package-manager registries are separate publication channels. At the time this
artifact train was prepared:

- npm remains on runtime packages `1.3.9`
- PyPI remains on runtime package `1.3.4`
- NuGet remains on `CoAkka.Runtime` `1.3.3`
- Go modules advances through tag `v1.3.11`
- SwiftPM advances through tag `v1.3.3`

Do not infer registry publication from the presence of a verified package file
in the artifact mirror. The compatibility matrix names the current version for
each channel.
