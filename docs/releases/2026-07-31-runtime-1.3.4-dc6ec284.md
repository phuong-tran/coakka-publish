# Runtime 1.3.4 Public Artifact Train

Date: 2026-07-31

This release refreshes the public runtime artifact train over native generation
`1.3.4+dc6ec284`.

It supersedes the prepared `1.3.3+282f3ad` artifact train. The earlier Linux
ARM64 shared library could pass build, export, and dependency checks but fail
when loaded late by a connector host with:

```text
cannot allocate memory in static TLS block
```

The AArch64 public-artifact link now disables TLS relaxation, and the native
dependency gate rejects `R_AARCH64_TLS_TPREL*` relocations. The corrected
library was loaded and exercised inside the Debian Node.js/Python container
path before the ecosystem packages were rebuilt.

## Native Boundary

The native package is published at:

```text
runtime/native/releases/1.3.4+dc6ec284/
```

The package keeps the host-facing runtime contract on the public C ABI. Public
native libraries expose the reviewed 88-symbol surface and pass platform
dependency and export gates. Generated protobuf, Abseil, C++ runtime internals,
and private transport schema are not part of the public dynamic-library
surface.

Do not infer registry publication from the presence of a verified package file
in the artifact mirror. The compatibility matrix names the current version for
each channel.
