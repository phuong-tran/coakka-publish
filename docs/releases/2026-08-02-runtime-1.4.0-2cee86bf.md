# CoAkka Runtime 1.4.0

Runtime `1.4.0` aligns the public native C ABI, language connectors, framework
adapters, documentation, and auditable native consumer tests around source
snapshot `2cee86bf89f38725aa763bb3abd96b64a904875d`.

## Artifact Identity

- Native generation: `1.4.0+2cee86bf`
- Connector generation: `1.4.0+2cee86bf-ec4902c`
- Python package projection: `1.4.5` from connector `77c9db8`
- npm package projection: `1.4.5` from connector `2c0c598`
- NuGet package projection: `1.4.5` from connector `562028d`
- Maven generation: `1.4.0-g2cee86bf-ec4902c`
- Native platforms: Linux ARM64, macOS ARM64, and Windows x86-64
- Public C exports: 101 on every included native platform

Each release directory contains a machine-readable manifest and
`SHA256SUMS`. The root [`artifacts/public-artifacts.tsv`](../../artifacts/public-artifacts.tsv)
is the authoritative download ledger.

## Connector Surface

The release includes JVM, Spring Boot, Quarkus, Node.js, Bun, Electron,
Python, Go, C#, Rust, Swift, Tauri, Mojo, and Zig artifacts. Every connector
uses the core capability and configuration contract for startup connection
strategy, structured atomic apply results, and TLS/mTLS credential reload.

Connection strategy, TLS/mTLS, and failure semantics are documented in the
[connection strategy guide](../connection-strategies.md),
[TLS/mTLS guide](../tls-and-mtls.md), and
[troubleshooting guide](../troubleshooting.md).

## Verification

- Native libraries pass dependency and exact 101-export checks.
- The JVM JAR loads its embedded runtime and reports version `1.4.0`, source
  snapshot `2cee86bf`, and capability mask `221`.
- Language package dry-runs install or unpack into clean consumers and execute
  their platform-appropriate smoke tests.
- The root [`runtime-test/`](../../runtime-test/README.md) covers request/reply,
  bounded admission, all four connection strategies, structured rejection,
  static analysis, and consumer-side ASan/UBSan controls.
- Linux ARM64 CI builds that public harness against the exact released 1.4.0
  archive, then runs both the workload and four-mode connection-strategy
  executables with ASan/UBSan. This instruments the public consumer source, not
  the closed runtime binary.
- On macOS ARM64, the public C11 harness passes static analysis across all nine
  translation units, request/reply `64/64`, connection strategy `4/4`, and
  both consumer-side ASan/UBSan executables with Homebrew LLVM 22.1.5. The
  troubleshooting guide records the AppleClang sanitizer-runtime stall that
  can occur before `main` on affected hosts.
- TLS/mTLS conformance covers all four connection strategies; failed
  credential reload preserves the active configuration.
- `coakka-client` and `coakka-runtime-inspect` 1.4.0 macOS ARM64 bundles pass
  unpacked dependency and command smokes. Linux and Windows tool archives keep
  their separately recorded prior generations until matching native builds are
  available.

## Platform Trust

The 1.4.0 files are distributed without publisher signing. SHA-256 verification
is required, and users may apply their own platform signing. OS-specific trust,
dependency, and loader guidance is in
[troubleshooting](../troubleshooting.md).
