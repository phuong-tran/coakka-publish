# CoAkka Public Artifact License 1.1

Effective 2026-08-03, CoAkka Public Artifact License 1.1 replaces version 1.0
for every artifact currently distributed from `coakka-publish` or an official
release page. This includes artifacts first published before the effective
date, including CoAkka Runtime 1.4.0. An embedded copy of version 1.0 is
superseded by version 1.1.

Version 1.1 permits, without a separate agreement:

- all included capabilities in production
- internal business and commercial workloads
- applications that bundle unmodified CoAkka artifacts
- SaaS and hosted applications that use CoAkka as an internal component
- customer distribution of those applications with notices preserved

A separate agreement remains required for a Managed CoAkka Service or an
offering whose primary or substantial value is providing CoAkka itself as a
runtime, control plane, appliance, cloud image, infrastructure product, or
marketplace service.

The restriction depends on what is offered, not on company size or industry.
The license revision does not introduce a runtime activation gate and does not
change binary bytes, checksums, publisher-signing status, capability masks, or
the separate Apache-2.0 license used by `coakka-samples`.

Read the governing terms in [`LICENSE.md`](../../LICENSE.md). For a legal
interpretation or Managed CoAkka Service agreement, use [`SUPPORT.md`](../../SUPPORT.md).
