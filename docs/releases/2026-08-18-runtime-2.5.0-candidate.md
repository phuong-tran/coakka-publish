# Runtime 2.5.0 coordinated candidate

The private release branch now carries one coordinated Runtime `2.5.0`
candidate from Core source
`4b65d0b2256037bf7fc180bfa6df8c41efc1dd6a`.

Candidate contents:

- native C ABI archives for Linux ARM64/x86-64, macOS ARM64, and Windows
  ARM64/x86-64
- JVM, Node.js, Bun, Electron, Python, Go, C#, Rust, Swift, Tauri, Mojo, and
  Zig connector packages from connector source `f36c396`, staged by commit
  `eb62ec8`
- `coakka-client` and `coakka-runtime-inspect` archives for the same five
  native platforms
- File Lane, Stream Lane, and lane-owner-grant native capability in the exact
  Core generation

All artifact paths are checksum-pinned in `artifacts/public-artifacts.tsv`.
The first Linux staging was rejected because its binaries required
`GLIBC_2.38`. Publish artifact commit
`53ade103faf819f180c6cb518d5d4d8c4e855861` replaces both Linux payloads with
Debian 12/glibc 2.36 builds while retaining the unchanged macOS and Windows
bytes. Raspberry Pi 5 execution passes the ARM64 public C consumer, pressure,
File Lane, Stream Lane, Client, and Inspect. Core Actions run `32131181333`
passes the matching Debian 12 x86-64 native, Client, and Inspect gates.

Language package readiness and packaged execution pass. Corrected connector
Actions run `32115140272` passes all 17 language/framework/platform jobs on
commit `2050d31`. Windows tool evidence remains Actions run `32115663861` over
the byte-identical Windows archives originally staged by Publish commit
`d5cff2a7922470b4b33bd48cac2b472bb75acbc4`. Samples commit
`2c93017aa114ea0f88d8cd92c69a665aacb5e092` passes artifact pins and the
Client, Inspect, Tauri, and Electron release lanes.

This branch is a release-ready restaged candidate, not a publication event.
Publication is deferred until credentials are available and a coordinated
release action is explicitly opened. That action creates the dedicated Go and
Swift export tags, publishes registry coordinates, verifies downloaded
packages, and only then moves public `current` pointers. Candidate preparation
does not perform those operations and makes no broader production-soak claim.
