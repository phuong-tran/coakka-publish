# Runtime 2.5.0 coordinated candidate

The private release branch now carries one coordinated Runtime `2.5.0`
candidate from Core source
`4b65d0b2256037bf7fc180bfa6df8c41efc1dd6a`.

Candidate contents:

- native C ABI archives for Linux ARM64/x86-64, macOS ARM64, and Windows
  ARM64/x86-64
- JVM, Node.js, Bun, Electron, Python, Go, C#, Rust, Swift, Tauri, Mojo, and
  Zig connector packages from connector source `f36c396`, staged by commit
  `e75df01`
- `coakka-client` and `coakka-runtime-inspect` archives for the same five
  native platforms
- File Lane, Stream Lane, and lane-owner-grant native capability in the exact
  Core generation

All artifact paths are checksum-pinned in `artifacts/public-artifacts.tsv`.
Language package readiness and packaged execution pass. Tool command execution
passes on macOS ARM64, Linux ARM64/x86-64, and Windows ARM64. Windows x86-64
matching-host tool execution remains a release-day gate.

This branch is a candidate, not a publication event. Tags, current pointers,
package registries, and production-support claims remain closed until the
coordinated release gate opens.
