# Logger Bun Artifacts

The current Bun logger package is published under:

- `logger/bun/releases/1.2.1+f50756ebff0d-6fdcc69/coakka-logger-bun-1.2.1.tgz`

It embeds the current logger native package for macOS, Linux, and Windows on
`aarch64` and `x86_64`. Normal Bun consumers install the tarball directly and
do not need to install a separate native logger package.
