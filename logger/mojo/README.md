# logger/mojo

This lane stores source-first Mojo logger connector drops.

Published releases live under:

```text
logger/mojo/releases/<release-dir>/
```

Each release directory contains:

- `coakka-logger-mojo-<version>-source.tar.gz`
- `manifest.json`
- `SHA256SUMS`
- `README.md`
- `CONSUMING.md`
