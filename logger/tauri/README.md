# Logger Tauri Artifacts

The current Tauri logger source package is published under:

- `logger/tauri/releases/1.2.1+f50756ebff0d-3e8a6ae/coakka-logger-tauri-intents-1.2.1-source.tar.gz`

It is a Rust source package with bundled logger natives. WebView JavaScript
sends log intents through a Tauri command; Rust owns validation, logger
lifecycle, queue pressure, and result projection.
