# CoAkka Runtime Test downloads

Download the runner for your operating system and CPU to try CoAkka Runtime
through its public C interface. Each archive includes the matching Community
Core 3.2 library and ready-to-run tests.

**[Choose a download and verify SHA-256](../../../docs/coakka-runtime/releases/2026-11-05-core-runtime-test-3.2.md)** ·
[Run the smoke test](releases/3.2+f9e5a632d2d046a5b4e89d5ce0c9042aee5c7b45/README.md#run-the-smoke-test)

The archives are unsigned. The runner checks requests and replies, admission
under load, concurrent callers, route updates, connection settings, File and
Stream. See [what each check covers](releases/3.2+f9e5a632d2d046a5b4e89d5ce0c9042aee5c7b45/SYSTEMS-AUDIT.md).

If you want to review the tests or build them yourself, start with
[CoAkka Runtime Test source](../../../coakka-runtime/coakka-runtime-test/README.md).
For previous packages, see the [release archive](releases/).
