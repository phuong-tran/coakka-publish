# Native License

The included macOS ARM64, Linux ARM64/x86-64, and Windows ARM64/x86-64 runtime libraries
follow the terms documented by `coakka-publish` for the matching runtime
generation.

Publisher signing is currently absent. The package does not claim Apple
Developer ID/notarization or Windows Authenticode identity. See the common
troubleshooting guide for checksum verification and platform trust prompts.
